모든 도로가 일방통행인 DAG에서 가장 오래 걸리는 경로의 시간과, 그 경로에 속한 도로 수를 구하는 문제입니다. 위상 정렬로 임계경로 배열을 완성하고, 역방향 그래프로 역추적하는 2단계 접근이 핵심입니다.

<!-- truncate -->

## 문제 설명

한걸음(시작 도시)에서 로마(도착 도시)로 향하는 사람들이 있습니다. 모든 도로는 일방통행이며 사이클이 없습니다(DAG). 가장 늦게 도착하는 사람의 시간을 출력하고, 그 사람이 지나온 도로의 수를 출력합니다.

**입력 조건**
- 도시 수 $N$: $1 \leq N \leq 10,000$
- 도로 수 $M$: $1 \leq M \leq 100,000$
- 각 도로의 이동 시간 $w$: $1 \leq w \leq 10,000$

[백준 1948번](https://www.acmicpc.net/problem/1948)

## 핵심 전략: 위상 정렬 + 역방향 역추적

### Step 1 — 정방향 위상 정렬로 임계경로 배열 완성

시작점 `s`에서 위상 정렬을 진행하면서, 각 도시에 도달하는 **최대 시간**을 `ins[]`에 기록합니다.

```
ins[d] = Math.max(ins[d], ins[now] + w)
```

"모든 사람이 모이려면 가장 늦게 도착하는 사람을 기다려야 한다"는 원리입니다. 단순히 덮어쓰면 안 되고 반드시 `Math.max`를 써야 합니다.

### Step 2 — 역방향 그래프로 유효 도로 카운팅

도착점 `e`에서 역방향 그래프를 따라 거슬러 올라가며, 아래 조건을 만족하는 도로만 셉니다.

```
ins[now] == ins[prev.d] + prev.w
```

이 조건이 참인 도로만 임계경로에 기여한 도로입니다. 같은 도시를 여러 번 큐에 넣을 수는 없지만(visited), **도로는 중복 없이 모두 세야** 합니다.

## 내가 막혔던 포인트들

### 자료구조 선택 — 3중 리스트의 유혹

처음엔 `ArrayList<ArrayList<ArrayList<Integer>>>` 같은 3중 구조를 고민했습니다. 목적지와 가중치를 함께 저장하려다 보니 차원이 늘어난 것인데, 이건 `Edge` 클래스 하나로 깔끔하게 해결됩니다.

```java
class Edge {
    int d; // 목적지
    int w; // 가중치
}
// 인접 리스트: ArrayList<ArrayList<Edge>>
```

인접 행렬 대신 인접 리스트를 쓰는 이유도 명확합니다. $N=10,000$인 인접 행렬은 $10^8$ 칸이 필요해 메모리 초과가 나지만, 인접 리스트는 $O(V+E)$로 딱 필요한 만큼만 씁니다.

### 초기화 실수 — 바깥 바구니를 반복문 안에서 선언

```java
// 틀린 방식 (반복문 안에서 node를 새로 생성)
for (int i = 0; i <= n; i++) {
    ArrayList<ArrayList<Edge>> node = new ArrayList<>(); // 매번 초기화됨!
    node.add(new ArrayList<>());
}

// 맞는 방식
ArrayList<ArrayList<Edge>> node = new ArrayList<>(); // 한 번만 생성
for (int i = 0; i <= n; i++) {
    node.add(new ArrayList<>()); // 내부 주머니만 추가
}
```

바깥 바구니를 루프 안에서 선언하면 매 반복마다 새로 만들어져 데이터가 날아갑니다.

### 임계경로 갱신 — `=`가 아니라 `Math.max`

```java
ins[d] = ins[now] + w;        // 틀림 — 나중에 오는 경로가 덮어쓸 수 있음
ins[d] = Math.max(ins[d], ins[now] + w);  // 맞음 — 최대값 유지
```

여러 경로로 같은 도시에 도달할 수 있고, 가장 늦게 도착하는 시간을 알아야 합니다.

### 역추적 — 도로는 세고 도시는 visited로 막기

마름모꼴 경로가 딜레마였습니다.

```
1 → 2 → 4
1 → 3 → 2 → 4
```

도착점 4에서 역추적하면 2를 두 번 방문하게 됩니다. 도시 2를 재방문하면 도로 `1→2`를 중복으로 세게 되므로, **도시(노드)는 `visited`로 막고 도로(엣지)는 모두 셉니다**.

```java
if (ins[now] == ins[prev.d] + prev.w) {
    count++;                        // 도로는 무조건 카운트
    if (!visited[prev.d]) {         // 도시는 한 번만 큐에 추가
        visited[prev.d] = true;
        rq.add(prev.d);
    }
}
```

## 풀이 코드

```java
import java.io.*;
import java.util.*;

public class Main {

    public static void main(String[] args) throws IOException {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();

        ArrayList<ArrayList<Edge>> node = new ArrayList<>();
        ArrayList<ArrayList<Edge>> reverse = new ArrayList<>();
        int[] dim = new int[n + 1]; // 진입차수
        int[] ins = new int[n + 1]; // 임계경로(최대 시간)

        for (int i = 0; i <= n; i++) {
            node.add(new ArrayList<>());
            reverse.add(new ArrayList<>());
        }

        int m = sc.nextInt();
        for (int i = 0; i < m; i++) {
            int u = sc.nextInt(), v = sc.nextInt(), w = sc.nextInt();
            node.get(u).add(new Edge(v, w));
            reverse.get(v).add(new Edge(u, w));
            dim[v]++;
        }

        int s = sc.nextInt(), e = sc.nextInt();

        // Step 1: 위상 정렬로 임계경로 배열 완성
        Queue<Integer> q = new LinkedList<>();
        q.add(s);
        while (!q.isEmpty()) {
            int now = q.poll();
            for (Edge next : node.get(now)) {
                ins[next.d] = Math.max(ins[next.d], ins[now] + next.w);
                if (--dim[next.d] == 0) q.add(next.d);
            }
        }

        // Step 2: 역방향 역추적으로 유효 도로 카운팅
        Queue<Integer> rq = new LinkedList<>();
        boolean[] visited = new boolean[n + 1];
        int count = 0;
        rq.add(e);
        while (!rq.isEmpty()) {
            int now = rq.poll();
            for (Edge prev : reverse.get(now)) {
                if (ins[now] == ins[prev.d] + prev.w) {
                    count++;
                    if (!visited[prev.d]) {
                        visited[prev.d] = true;
                        rq.add(prev.d);
                    }
                }
            }
        }

        System.out.println(ins[e]);
        System.out.println(count);
    }
}

class Edge {
    int d, w;
    Edge(int d, int w) { this.d = d; this.w = w; }
}
```

## 시간복잡도

| 단계 | 복잡도 |
|------|--------|
| 위상 정렬 (Step 1) | $O(V + E)$ |
| 역방향 역추적 (Step 2) | $O(V + E)$ |
| **전체** | $O(V + E)$ |

$V = 10,000$, $E = 100,000$ 기준으로 약 110,000번 연산이므로 충분히 빠릅니다.

> **Scanner vs BufferedReader**: 이 문제에서는 Scanner를 써도 통과되지만, 입력량이 많은 문제에서는 `BufferedReader` + `StringTokenizer` 조합이 약 3~5배 빠릅니다. $M$이 크다면 교체하는 습관을 들이는 게 좋습니다.

## 배운 점

위상 정렬은 "어떤 순서로 처리해야 하는가"뿐 아니라, **DAG에서의 최장 경로(임계경로)** 를 구하는 데도 강력합니다. 역방향 그래프를 함께 구성해두는 패턴은 최단/최장 경로 문제에서 자주 등장하니 익혀두면 좋습니다.

핵심 판단 기준 요약:
- 그래프에 사이클이 없고 순서가 있다 → **위상 정렬**
- 최장 경로가 필요하다 → **임계경로 배열 + Math.max**
- 어떤 경로가 기여했는지 역추적이 필요하다 → **역방향 그래프 + 조건 검증**
