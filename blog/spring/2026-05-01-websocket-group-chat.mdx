// 프론트: 채팅창 열기
function goSocket(grId, memId) {

        @RequestParam String gr_id,

```javascript
// 프론트: WebSocket 연결 (채팅방 뷰에서)
const ws = new WebSocket(
    `ws://${location.host}${contextPath}/ws/chat`
);

ws.onopen = () => {
    // 입장 메시지 — 핸들러에서 prefix로 분기
    ws.send(`#nick_${nick}`);
};

ws.onmessage = (e) => {
    const data = e.data;
    const li = document.createElement('li');
    // 내 메시지 / 상대 메시지 / 알림 분기
    if (data.startsWith('나:')) li.className = 'mine';
    else if (data.startsWith('#notify')) li.className = 'notify';
    else li.className = 'other';
    li.innerHTML = data.replace('#notify', '');
    msgList.appendChild(li);
    msgList.scrollTop = msgList.scrollHeight;
};
```

### 종료 흐름 전체 연결

```java
// 서버: REST 엔드포인트로 참여자 제거
@PostMapping("/socket_out")
@ResponseBody
public void socketOut(@RequestParam String gr_id,
                      @RequestParam String mem_id) {
    Map<String, List<String>> chatList =
        (Map<String, List<String>>) ctx.getAttribute("chatList");
    List<String> list = chatList.get(gr_id);
    if (list != null) list.remove(mem_id);
}
```

> `ws.close()`를 먼저 호출하면 서버의 `afterConnectionClosed()`가 실행되어 세션 목록은 자동 정리됩니다. `sendBeacon`으로 호출하는 REST API는 **애플리케이션 스코프의 참여자 목록(chatList)** 을 추가로 정리하는 용도입니다.

## 한눈에 정리

| 구성 요소 | 역할 | 핵심 포인트 |
|---|---|---|
| `HttpSessionHandshakeInterceptor` | HTTP 세션 → WS 세션 attributes 복사 | 핸들러에서 `session.getAttributes().get("gr_id")` |
| `CopyOnWriteArrayList` | 세션 목록 스레드 안전 저장 | 읽기 多 / 쓰기 少 환경에 최적 |
| `ConcurrentHashMap` | 세션↔닉네임, 그룹↔멤버 맵 | 버킷 단위 락으로 HashMap보다 안전·빠름 |
| `Application Scope` | 전체 사용자 공유 참여자 목록 | `ServletContext.getAttribute("chatList")` |
| `sendBeacon` | 페이지 종료 시 안정적 데이터 전송 | fire-and-forget, 응답 불가 |
| `isClosing` 플래그 | 종료 로직 중복 실행 방지 | 버튼 클릭 + beforeunload 동시 실행 차단 |
